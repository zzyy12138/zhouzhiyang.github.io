这段时间把「大模型」从概念到能上手用，大致理了一遍。笔记不求全面，主要记自己真正卡住、后来又想通的点。

## 先说清楚：什么叫大模型

口语里说的大模型，多半指参数量到十亿量级以上、在海量文本上预训练过的 Transformer 类模型。参数量只是门槛，真正让它「好用」的是：通用表示、可迁移、再微调或提示就能盖住很多下游任务。

我自己的粗分法：

- **语言**：GPT / Claude / LLaMA、BERT 一类理解模型、CodeLlama 这类偏代码的
- **视觉**：CLIP、BLIP；生成侧是 Diffusion（Stable Diffusion、DALL·E）
- **语音**：TTS（VITS、XTTS）、STT（Whisper、Wav2Vec）
- **多模态**：GPT-4V、Gemini、Qwen-VL——图文甚至音视频一起吃

架构上现在还是 Transformer 一家独大：编码器（BERT）、解码器（GPT）、编解码器（T5）。Diffusion 管图像生成；Mamba / RetNet 这类替代方案值得盯着，但生产里我还是会先选成熟的 Transformer 栈。

## 时间线（按自己用过的节点记）

2017 Attention Is All You Need → 2018 BERT / GPT-1 → 2019 GPT-2 → 2020 GPT-3（175B，第一次让人觉得「规模真有用」）→ 2022 ChatGPT 把对话产品打穿 → 2023 GPT-4、Claude、LLaMA 2 → 之后多模态、推理模型和开源中文模型卷得很快。

读论文和用产品是两件事：论文讲 scaling law，产品讲延迟、成本和幻觉。两边都得看。

## 核心技术：真正干活的三块

**Transformer。** Self-Attention 让每个 token 看全序列；多头从不同子空间抓关系；位置编码补上顺序信息（现在常用 RoPE）；FFN 负责非线性容量。没有它，现在这波 LLM 基本起不来。

**预训练。** 无标注文本上做自监督：GPT 系预测下一个 token；BERT 系做掩码；T5 把任务统一成 text-to-text。数据是网页、书、代码，TB 级，清洗比堆模型还烦。

**微调与对齐。** 全量微调效果最好也最贵。日常我更常上 LoRA / QLoRA：改很少参数就能适配业务。指令微调让模型听人话；RLHF / DPO 一类则是把输出往人类偏好上掰——ChatGPT 那一档体验很大程度来自对齐，而不只是更大的预训练。

## 能力边界（用着用着就会撞上）

语言侧：分类、摘要、对话、写代码都还行；多步推理和数学要看模型和提示，别盲目信。多模态侧：看图说话、视觉问答已经能做原型，视频和长音频仍贵且不稳定。

落地常见几类：

- 内容与代码生成、客服对话
- 知识问答（尤其是接了 RAG 的）
- 图文理解、语音助手链路（STT → LLM → TTS）

## 优点和坑

通用、可迁移、规模上来后有涌现，这些都是真的。但训练和推理都吃 GPU；延迟一上去产品就废；幻觉会一本正经胡说；安全与合规也绕不过去。选型时我一般先问：要不要本地、中文好不好、能不能接受按 token 付费——比纠结「参数量谁更大」有用。

## 我现在怎么看趋势

参数还在涨，但效率（量化、蒸馏、稀疏注意力）和成本更决定能不能上线。多模态在往统一架构走；垂直领域小模型和工具调用（function calling）在业务里往往比「纯聊天」更值钱。边缘侧能跑的小模型也越来越多，隐私场景会优先本地。

自学顺序我自己走过的是：概念 → Transformer → 预训练/微调 → 提示词 → 评估指标 → 再碰多模态和部署。别一上来就追最新发布会，把 attention 和采样参数搞明白，后面换模型成本会低很多。
