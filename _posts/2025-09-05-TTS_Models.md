TTS 把文本变成波形。拼接式、HMM 参数合成那套听久了都「电子味」；深度学习之后自然度跃一截，现在麻烦更多在：多语、克隆、实时延迟，以及别把别人的声音乱用。

## 管线怎么演变

经典神经 TTS 常拆两段：文本 → Mel 谱（声学模型）→ 波形（声码器）。**Tacotron / Tacotron 2** 用 seq2seq + attention 出 Mel，再接 WaveNet / HiFi-GAN。Attention 对不齐时会出现吞字、重复，训练也脆。

**VITS** 把声学和声码器端到端捏在一起，VAE + 对抗训练，音质和速度都更讨喜，开源中文项目里很常见。推理时少维护一套独立声码器，运维省心。

再往后是「大模型味」的多语 TTS：**XTTS** 一类支持少样本 / 零样本音色克隆——几秒参考音就能说别的句子，甚至跨语言。Bark 还能玩音效、简单哼唱，可控性和稳定性要自己权衡。Microsoft **SpeechT5** 则走统一语音框架（合成和识别共享思路）。

## 声码器和特征

Mel 谱是主流中间表示；F0、能量、时长影响韵律。声码器从 Griffin-Lim（糊）到 WaveNet（慢）再到 **HiFi-GAN / Vocos**（又快又亮）。端到端模型把这块内化了，但调「太闷 / 太尖」时仍要懂一点谱和响度。

## XTTS：我实际会先试的克隆路径

```python
from TTS.api import TTS

tts = TTS("tts_models/multilingual/multi-dataset/xtts_v2")
tts.tts_to_file(
    text="先用短句测克隆像不像，再上长文。",
    speaker_wav="ref_10s.wav",  # 干净、单人、少混响更好
    language="zh",
    file_path="out.wav",
)
```

参考音脏、多人叠音、BGM 大，克隆会垮。长段落我按标点切句再拼接，并留句间静音，否则一口气读到缺氧。商用还要解决音色授权——技术可行 ≠ 法律可行。

## 应用和评估

智能助手播报、有声内容、视频多语配音、无障碍读屏、语言学习跟读，都是常见场景。评估上：

- 主观：**MOS**（1～5）听感
- 客观：MCD、F0 RMSE；克隆还要说话人相似度
- 业务：是否听清专有名词、数字、英文混读

自动指标只能辅助；上线前找几个人盲听比盯 loss 有用。

## 优化与坑

质量：干净录音、统一采样率、文本前端（多音字、数字读法、英文缩写）往往比换模型收益更大。中文前端没调好，再强的声学模型也读得像外国人念拼音。

速度：量化、小模型、流式合成（先出首包音频）。实时对话里，TTS 尾延迟和 LLM 首字延迟一样敏感。

我的取舍：单说话人固定音色 → VITS / 精调小模型；要快速换音色、多语 → XTTS 路线；要极致品牌音 → 请真人录一套再考虑微调。先把文本规范化和切句做对，再谈模型。
